# 💰 Coinly – Personal Finance Tracker

## Introduction

**Coinly** is a personal finance management web application that helps users keep track of their income and expenses in one place. It provides an easy way to manage daily transactions, organize them into categories, and view financial summaries through interactive charts. Coinly is designed to help users understand their spending habits and make better financial decisions.

---

## Features

* 🔐 User Authentication (Register & Login)
* 💵 Add, Edit, and Delete Income & Expenses
* 📂 Manage Expense Categories
* 📊 Dashboard with Financial Summary
* 📈 Charts for Income and Expenses
* 🔍 Search and Filter Transactions
* 👤 User & Admin Roles
