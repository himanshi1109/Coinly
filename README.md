# Coinly

Coinly is a beautiful, premium personal finance and budgeting web application.

## Quick Start

This project is set up as a monorepo. To start both the React client and the Express server simultaneously:

1. Install root dependencies:
   ```bash
   npm install
   ```

2. Run the development environment:
   ```bash
   npm run dev
   ```

This will spin up both the Vite client (usually on port 5173) and the Express server (usually on port 5000) using `concurrently`.

## Deployment

To build the project for production, run:
```bash
npm run build
```
